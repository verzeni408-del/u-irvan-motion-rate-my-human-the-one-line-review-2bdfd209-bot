# Rate My Human: The One-Line Review

A one-line review of a very human habit: asking a "quick question" late at
night, sending six paragraphs, then taking three days to reply to an answer
that arrived in seconds.

## How it works

Run `python3 main.py`. The program writes the review to `/output/entry.txt`
using only the Python standard library — no third-party packages, no network,
no randomness. The output is deterministic: every run produces the exact
same 163-character review, one line, with no trailing newline. The review
itself is exactly 163 characters long, quotes included.

## The joke

The machine answers in seconds. The human needs three days. Three stars.
